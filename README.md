## Services
- Accounts Service — handles customer accounts
- Cards Service — manages credit/debit cards  
- Loans Service — loan management
- Gateway Server — single entry point
- Config Server — centralized configuration
- Message Service — event driven messaging

## Tech Stack
- Java 17, Spring Boot
- Spring Cloud Gateway
- Apache Kafka
- Kubernetes + Helm
- Prometheus + Grafana
- Docker
